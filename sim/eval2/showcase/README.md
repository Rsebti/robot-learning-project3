# Eval 2 env showcase

This directory contains a snapshot of the Eval 2 environment for
teammates to browse without running Isaac Sim locally.

## How to refresh

The PNG screenshots and metadata in this directory are auto-generated by
[`../scripts/showcase_env.py`](../scripts/showcase_env.py). Re-run from
the project root :

```powershell
cd C:\Users\user\Desktop\MA2\robot-learning-project3
$env:RUST_LOG = "error"
C:/Users/user/Desktop/MA2/isaac/isaac_so_arm101/.venv/Scripts/python.exe `
  sim/eval2/scripts/showcase_env.py `
  --task Isaac-LeIsaac-SO101-Lift-Visual-V215-Play-v0 `
  --headless --enable_cameras
```

The script will overwrite `wrist_cam_home.png` and `README.md` here.

## What's in here

- **`README.md`** — auto-generated scene info (this file is the placeholder; will be overwritten on first run)
- **`wrist_cam_home.png`** — 224×224 RGB view from the wrist camera at the robot's home pose (= what the policy network sees as image input)

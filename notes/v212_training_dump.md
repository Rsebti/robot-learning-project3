## How to interpret Episode_Reward values

In rsl_rl logs, `Episode_Reward/<term>` = `mean(sum_of_weighted_term_per_episode) / max_episode_length_s`. With `max_episode_length_s = 5`:

- `sum_per_ep = Episode_Reward * 5`
- For reaching_object (w=1, max=1/step): per-step value = sum_per_ep / 150 = Episode_Reward / 30. Then `d = atanh(1 - per_step) * 0.15` gives avg EE-cube distance.
- For grasping_cube (w=5, binary): n_grasp_steps_per_ep = sum_per_ep / 5 = Episode_Reward
- For lifting_object (w=10, binary): n_lift_steps_per_ep = sum_per_ep / 10 = Episode_Reward / 2
- For ee_to_cube_distance (w=-1, raw distance in meters): per-step distance = -Episode_Reward / 30 in meters
- For success_bonus (w=2500, sparse terminal): n_success_per_ep = sum_per_ep / 2500 = Episode_Reward / 500. If Episode_Reward = 1.0, that's 0.002 = 0.2% success rate.
